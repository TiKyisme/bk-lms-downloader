# Support

- **Bug report:** use the [bug report form](https://github.com/TiKyisme/bk-lms-downloader/issues/new?template=bug_report.yml).
- **Feature request:** use the [feature request form](https://github.com/TiKyisme/bk-lms-downloader/issues/new?template=feature_request.yml).
- **Usage question:** review the [README](README.md) and [documentation index](docs/README.md), then open a clearly titled GitHub issue if the answer is not covered.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md); do not report sensitive issues publicly.

Never attach passwords, cookies, session tokens, Authorization headers, private
course material, full LMS exports, or personal information to issues or comments.
