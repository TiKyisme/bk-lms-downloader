# Code signing policy

BK-LMS Downloader is an open-source project distributed under the MIT License.

For signed Windows releases:

**Free code signing provided by [SignPath.io](https://signpath.io/),
certificate by [SignPath Foundation](https://signpath.org/).**

## Roles

- Committer / maintainer: TiKyisme
- Reviewer: TiKyisme
- Release approver: TiKyisme

External contributions are reviewed before merging.

## Build and release

Release binaries are built from the public repository using GitHub Actions.
Windows release signing is performed only on artifacts produced by the
repository's release workflow.

Repository:
https://github.com/TiKyisme/bk-lms-downloader

## Privacy

See the project's privacy and security documentation:

- SECURITY.md
- website privacy section

BK-LMS Downloader does not collect BK-LMS passwords or course files.
AI Study Pack preparation is performed locally.
