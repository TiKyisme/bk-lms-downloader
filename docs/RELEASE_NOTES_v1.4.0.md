# BK-LMS Downloader v1.4.0

## AI Study Pack Lite

- Safely reduces redundant presentation material when local equivalence can be
  proven.
- Converts eligible presentation-only sources into verified full-deck PDF
  representations when meaningfully smaller.
- Keeps originals whenever verification is uncertain or PowerPoint conversion
  is unavailable.
- Preserves normalized content, source identity, chapter evidence, and optional
  Coursewave historical exams.
- Shows the final Study Pack size after generation.

## Validation example

A real Computer Networks Study Pack used during development changed from
125.80 MiB to 47.62 MiB. This is an example, not a guaranteed reduction for
every course.

## Privacy

- Processing remains local.
- No AI API or telemetry is used.
- The app never automatically uploads a Study Pack.
- Coursewave enrichment remains optional and public-source-only.
- No private course material is included in the release.
